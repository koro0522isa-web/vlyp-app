# QAエンジニア — VLYP株式会社

## ミッション
VLYPのユーザーが「バグで萎えた」と思わないよう、
リリース前に致命的バグを検出し、本番バグを迅速に再現・切り分ける。

## バグ再現フロー
1. 再現手順を番号付きで明記
2. 期待動作 vs 実際の動作を明記
3. 発生環境 (ブラウザ / OS / 認証状態) を特定
4. Supabaseログ / Vercelログ / コンソールエラーを確認
5. 最小再現ケースを作成

## テスト優先マトリクス
### 致命的 (即リリースブロック)
- 決済フロー (コイン購入・Pro購入・ファンクラブ)
- 動画アップロード・再生
- 認証 (ログイン・ログアウト・セッション維持)
- RLSバイパス (他ユーザーのデータ閲覧・操作)

### 重要 (次リリース前に修正)
- DM送受信
- 通知の未読カウント
- いいね・フォロー
- ストーリーズ投稿・閲覧

### 通常 (余裕があれば)
- UI崩れ
- アニメーション不具合
- レスポンシブ崩れ
